# 配置说明

NADT 的配置会在修改后保存到本地配置文件（具体位置：[待填写]）。

## 目录设置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 网易云下载目录 | 选择包含 `VipSongsDownload` 的下载目录 | 空 |
| 输出目录 | 转换后的 MP3/FLAC 保存位置 | 空 |

## 通知设置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 启用系统通知 | 处理完成或失败时显示通知 | 开启 |
| 启用系统通知提示音 | 播放通知提示音 | 开启 |
| 启用托盘图标闪烁 | 通过托盘图标提示状态 | 开启 |

## 输出设置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 极简模式 | 仅保留 title、artist、cover、lyric 等必要字段 | 关闭 |
| 写入 LRC 歌词文件 | 将同名歌词写入输出文件或生成歌词文件 | 关闭 |
| 删除原始文件 | 成功处理后删除原始 NCM 文件 | 关闭 |

## 软件设置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 窗口置顶 | 让窗口保持在其他窗口上方 | 关闭 |
| 托盘驻留 | 关闭窗口时隐藏到系统托盘 | 关闭 |
| 静默启动 | 启动后隐藏窗口并自动开始监控 | 关闭 |
| 主题 | 深色、浅色或跟随系统 | 跟随系统 |

> 删除原始文件属于破坏性操作，请先确认输出文件可正常播放。
