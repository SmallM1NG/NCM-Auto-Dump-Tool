# FAQ

## 找不到网易云下载目录怎么办？

请选择包含 `VipSongsDownload` 的下载根目录，或直接选择 `VipSongsDownload` 文件夹。[待补充默认路径]

## 文件没有自动处理怎么办？

请确认：

1. 下载目录设置正确；
2. 已点击“启用监控”；
3. 文件扩展名为 `.ncm`；
4. 运行日志中没有错误。

## 可以手动处理文件吗？

可以，将 `.ncm` 文件拖入软件窗口即可加入队列。同名 `.lrc` 文件会一并识别。

## 输出文件在哪里？

输出位置由“输出目录”决定。若未设置，请先选择输出目录。

## 如何停止监控？

点击主界面的“停止监控”按钮即可。

## 关闭窗口后程序还会运行吗？

启用“托盘驻留”后，关闭窗口会隐藏到系统托盘。[待补充托盘操作说明]

请前往 [GitHub Issues](https://github.com/SmallM1NG/NCM-Auto-Dump-Tool/issues)，附上版本、系统、复现步骤和日志文件。
